اصلاحات موبایل قالب آریا
========================

این بسته دو فایل ادیت‌شده دارد:

1) themes/DefaultTheme/src/resources/views/widgets/main-slider.blade.php
   - جلوگیری از نمایش لحظه‌ای اسلاید قبلی زیر اسلاید جدید در حالت موبایل.
   - بدون تغییر در ظاهر و عملکرد اسلایدر دسکتاپ.

2) themes/DefaultTheme/src/resources/views/partials/mobile-bottom-navigation.blade.php
   - جایگزینی گزینه «محصولات» با «دسته‌بندی» در نوار پایین موبایل.
   - بازشدن دسته‌بندی‌های اصلی در Bottom Sheet/پاپ‌آپ.
   - بستن با دکمه، لمس پس‌زمینه و کلید Escape.
   - حفظ جستجو، سبد خرید، خانه و حساب کاربری فعلی.

روش نصب
--------
فایل‌ها را دقیقاً در همین مسیرها روی سرور جایگزین کنید و سپس از ریشه پروژه اجرا کنید:

php artisan optimize:clear
php artisan view:clear

برای این تغییرات نیازی به npm build نیست؛ CSS و JavaScript موردنیاز داخل فایل‌های Blade قرار گرفته‌اند.

پیشنهاد: پیش از جایگزینی، از دو فایل فعلی سرور نسخه پشتیبان بگیرید.
