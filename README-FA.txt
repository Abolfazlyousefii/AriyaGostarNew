نسخه ترمیمی مگامنوی آریا

این نسخه به‌هم‌ریختگی هدر نسخه قبلی را اصلاح می‌کند.
مگامنو تا زمان آماده‌شدن CSS و JavaScript با ویژگی hidden مخفی است و وارد جریان صفحه نمی‌شود.
تمام کلاس‌های ظاهری با پیشوند axm- ایزوله شده‌اند.

نصب:
1. ZIP را در ریشه پروژه استخراج و فایل‌ها را جایگزین کنید.
2. اجرا کنید:
   php artisan migrate
   php artisan optimize:clear
   php artisan cache:clear
3. صفحه را با Ctrl + F5 تازه‌سازی کنید.

آپلود آیکن:
محصولات > دسته‌بندی‌ها > ایجاد یا ویرایش دسته‌بندی > آیکن مگامنو
فرمت پیشنهادی PNG یا WebP شفاف با اندازه 64×64 است.
