پیاده‌سازی پنل «کاربران آنلاین» فروشگاه آریا — نسخه تست لوکال
================================================================

این بسته شامل فایل‌های لازم برای:
- ثبت زنده بازدیدکنندگان فروشگاه
- نمایش کاربر مهمان یا ثبت‌نام‌شده و شماره تماس کاربر ثبت‌نامی
- نمایش دستگاه، مرورگر، سیستم‌عامل و موقعیت تقریبی
- نمایش صفحه و محصولی که کاربر در حال مشاهده است
- ثبت جستجوها، مشاهده محصول، تغییر سبد و شروع ثبت سفارش
- نمایش مشتریان داغ، محصولات پرتقاضا و سبدهای رهاشده

نکته مهم:
هیچ پکیج Composer یا NPM جدیدی لازم نیست. پروژه از قبل Jenssegers Agent را دارد.

------------------------------------------------------------
مرحله 1 — بکاپ
------------------------------------------------------------
قبل از جایگزینی فایل‌ها، از پوشه پروژه لوکال بکاپ بگیر:

C:\laragon\www\Ariya

------------------------------------------------------------
مرحله 2 — انتقال فایل‌ها
------------------------------------------------------------
محتویات همین بسته را داخل ریشه پروژه زیر کپی کن و فایل‌های همنام را Replace کن:

C:\laragon\www\Ariya

ساختار پوشه‌ها باید حفظ شود؛ مثلاً:

C:\laragon\www\Ariya\app\Models\LiveVisitor.php
C:\laragon\www\Ariya\routes\web.php
C:\laragon\www\Ariya\public\themes\defaultTheme\js\live-visitor-tracker.js

------------------------------------------------------------
مرحله 3 — اجرای Migration فقط برای همین قابلیت
------------------------------------------------------------
Terminal لارگون را داخل پوشه پروژه باز کن و اجرا کن:

cd C:\laragon\www\Ariya
php artisan optimize:clear
php artisan migrate --path=database/migrations/2026_07_28_120000_create_live_visitor_analytics_tables.php

استفاده از --path مهم است تا Migrationهای نامرتبط پروژه اجرا نشوند.

------------------------------------------------------------
مرحله 4 — اجرای سایت
------------------------------------------------------------
در صورت استفاده از artisan serve:

php artisan serve

سپس وارد پنل مدیریت شو و این آدرس را باز کن:

http://127.0.0.1:8000/admin/statistics/live-visitors

در منوی سمت راست پنل نیز گزینه «کاربران آنلاین» اضافه شده است.

------------------------------------------------------------
مرحله 5 — تست زنده
------------------------------------------------------------
1) صفحه پنل کاربران آنلاین را باز نگه دار.
2) در Incognito یا مرورگر دیگری، فروشگاه را باز کن:

http://127.0.0.1:8000

3) وارد صفحه محصولات شو، جستجو کن، یک محصول را باز کن و چیزی به سبد اضافه کن.
4) اطلاعات حداکثر طی 5 تا 15 ثانیه در پنل نمایش داده می‌شود.
5) برای شبیه‌سازی چند مشتری، چند مرورگر یا چند پروفایل Incognito جدا باز کن.

------------------------------------------------------------
رفتار موقعیت مکانی
------------------------------------------------------------
در لوکال، موقعیت به‌صورت «سیستم محلی، لوکال» نشان داده می‌شود.
روی سرور، کشور از هدر Cloudflare قابل دریافت است. برای شهر واقعی باید GeoIP سرور
فعال شود. این سیستم GPS دقیق گوشی را بدون اجازه کاربر دریافت نمی‌کند.

------------------------------------------------------------
خطاهای رایج
------------------------------------------------------------
1) خطای Table live_visitors doesn't exist
   Migration اجرا نشده است. دستور مرحله 3 را اجرا کن.

2) خطای Route not found
   اجرا کن:
   php artisan optimize:clear

3) کاربر در پنل نمایش داده نمی‌شود
   - DevTools مرورگر فروشگاه را باز کن.
   - در Network درخواست live-analytics/collect را بررسی کن.
   - صفحه فروشگاه را با Ctrl+F5 بازخوانی کن.
   - مطمئن شو فایل زیر وجود دارد:
     public/themes/defaultTheme/js/live-visitor-tracker.js

4) صفحه پنل درخواست تأیید رمز عبور می‌کند
   این رفتار Middleware فعلی پنل است؛ رمز مدیریت را مجدد وارد کن.

------------------------------------------------------------
بازگشت به حالت قبل
------------------------------------------------------------
برای حذف جدول‌های این قابلیت:

php artisan migrate:rollback --path=database/migrations/2026_07_28_120000_create_live_visitor_analytics_tables.php

سپس سه فایل جایگزین‌شده زیر را از بکاپ برگردان:
- routes/web.php
- resources/views/back/partials/sidebar.blade.php
- themes/DefaultTheme/src/resources/views/layouts/master.blade.php

و فایل‌های جدید این بسته را حذف کن.
